# TimberFall

Trees do not vanish, they tip over and crash to the ground.

Free plugin for Spigot and Paper, 1.21 up to 26.x, one jar, no dependencies. Java 21 or newer.

## Build

```
gradle build
```

The jar ends up in `delivery/`.
